# 클래스카드 매칭 자동화

개발자 도구 콘솔에서 실행하는 JavaScript로, 사용자가 시작한 클래스카드 매칭 게임 한 판의 텍스트 및 음성 문제를 자동으로 풉니다. 한 판에서 최대 14,000점까지 기록할 수 있으며, 게임 시작과 재도전은 사용자가 직접 누릅니다.

이 프로젝트는 GPT-6.1 Sol을 활용해 만들었습니다.

## 사용 방법

1. 클래스카드의 매칭 게임 페이지를 엽니다.
2. [자동화 스크립트](classcard-auto.js)의 전체 내용을 복사합니다.
3. 개발자 도구 콘솔을 열어 스크립트를 붙여 넣고 Enter를 누릅니다. Windows Chrome에서는 `Ctrl+Shift+J`로 콘솔을 열 수 있습니다.
4. 콘솔에 대기 상태가 표시되면 게임 시작 또는 재도전을 직접 누릅니다. 이미 게임이 진행 중이라면 스크립트가 실행을 시작합니다.
5. 스크립트는 한 게임이 끝나면 멈춥니다. 다음 판을 풀려면 `classcardAuto.start()`를 실행하고 시작 또는 재도전을 직접 누릅니다.

콘솔에서 사용할 수 있는 제어 명령은 다음과 같습니다.

```js
classcardAuto.status() // 실행 상태, 정답 쌍 수, 음성 카드 수, 점수, 오류 확인
classcardAuto.stop()   // 즉시 중지하고 예약된 추가 클릭 취소
classcardAuto.start()  // 새 게임을 기다리도록 실행
```

새 버전을 붙여 넣으면 기존 자동화 실행을 먼저 취소합니다. 현재 카드 선택이나 판정이 끝나지 않은 상태라면 선택이 풀린 뒤 다시 실행하세요.

## 기술 스택

- JavaScript: 별도 라이브러리나 빌드 과정이 없는 단일 브라우저 스크립트
- Chrome 개발자 도구 콘솔: 스크립트 실행 환경
- 브라우저 DOM API: 카드 내용 확인, `HTMLElement.click()`을 통한 클릭
- `MutationObserver`와 타이머: 화면 변화를 감지하고 게임 상태 확인

서버, 계정 연동, 별도의 패키지 설치는 필요하지 않습니다.

## 동작 원리

왼쪽 카드의 음성 아이콘에서 원본 카드 ID를 읽고, 클래스카드 화면에 로드된 목록에서 해당 카드의 뜻을 가져옵니다. 오른쪽 카드의 텍스트와 비교해 정답 쌍을 찾습니다. 화면의 정확한 뜻 일치를 먼저 확인하고, 필요한 경우 페이지에서 제공하는 `checkAnswer` 비교 함수와 카드에 등록된 대체 정답을 확인합니다. 음성 문제는 발음을 인식하지 않습니다. 화면에 남아 있는 원본 단어와 카드 ID를 사용하므로 단어가 숨겨져 있어도 대응할 수 있습니다.

정답을 찾으면 기존 게임의 카드 클릭 흐름을 사용합니다. 카드의 정답 표시와 점수 변화 등 화면에 나타나는 결과를 확인한 뒤 다음 쌍을 풉니다. Hurry UP 구간의 점수 변경도 반영합니다. 점수가 예상과 다르거나 오답으로 판정되면 중지합니다. 점수, 타이머, 게임 내부 배열, 저장 요청을 직접 변경하지 않습니다.

이미지 문제와 게임 페이지 구조 변경은 지원하지 않으며, 발견하면 추가 입력을 멈춥니다. 정답 판정은 최대 6초, 입력 가능한 정답 쌍 탐색은 최대 12초 기다립니다.
